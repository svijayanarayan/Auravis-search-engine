# AURAVIS V13 additions

- Search Fusion: combines typed text, voice input and offline image recognition into one query.
- Offline Semantic-Lite: small deterministic synonym/concept expansion; no new model or dependency, and exact search remains the base.
- Existing V12 features are preserved.


## V13.1 In-page Offline Learning Document
Education results now include an Open Learning Document button. It opens a right-side drawer without leaving Search. The document is built from local education data and works without internet while the local Flask app is running. Full lesson/video remains available separately.
